# Dataset

File: `Apartments_Prices_Dataset.csv` (5,578 rows, 11 columns, included in this folder).

Target: `price` (apartment price in EGP). The columns are text with units (`2,163,000 EGP`, `120 m²`, `3 rooms`) and some rows are shifted or contain impossible values; all of this is cleaned in the notebook. About 27% of the rows are duplicates and are removed.

Source: Egyptian real-estate listings (Kaggle — "Apartments Prices Dataset").
