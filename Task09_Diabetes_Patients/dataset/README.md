# Dataset

File: `diabetes_patients_10000_full.csv` (10,000 rows, 10 columns, included in this folder).

Columns: Patient_ID, Age, Gender, Blood_Sugar_Level, Creatinine, BMI, Urea, Cholesterol, HbA1c, Class. Target: `Class` (Diabetic / Non-Diabetic, about 91% / 9%). A few feature values (about 0.5%) are missing and are handled in the notebook.

Source: Kaggle — "Diabetes patients" dataset (looks synthetic: uniform ranges and a very clean separation).
