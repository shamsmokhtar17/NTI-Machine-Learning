# Dataset

File: `cars_data.csv` (1,000 rows, 8 columns, included in this folder).

Columns: Brand, Year, Mileage, Engine_Size, Fuel_Type, Transmission, Previous_Owners, Price. Target: `Price`. `Engine_Size` has 20 missing values (handled in the notebook).

Source: Kaggle — "Cars" used-car prices dataset.
