# Dataset

File: `Ames_Housing_Dataset.csv` (1,460 rows, 81 columns, included in this folder).

Target: `SalePrice` (sale price of the house in dollars). Many `NA` values mean "no such feature" (no alley, no pool, no garage...) and are handled in the notebook.

Source: Kaggle — "House Prices: Advanced Regression Techniques" (Ames, Iowa housing data).
